tier 2 — classes

Telling the user that something is happening, has happened, or has nothing to show. Five families: .toast, .spinner, .skeleton, .progress and .empty-state.

A toast confirms something that already happened and then goes away. Anything the user still has to act on is an .alert, which stays until the state changes.

Toast

.toast-stack is the only positioned element — it is fixed to the bottom-inline-end corner at z-index 600. Each toast is a plain block inside it, so an app renders the list and positions nothing. Here the stack is position:static so you can see it in place instead of pinned to the corner of your screen; in your app you drop that override.

Spinner

Sized in em, so it matches whatever text or button it sits in without a second class. .spinner-lg is the standalone size for a panel that is still loading.

Skeleton

Give each placeholder the height and width of the content that is coming, so nothing reflows when it arrives. Vary the line widths — identical bars read as a table, not a paragraph.

Progress

Determinate: set the inline width on .progress-bar — the one value only your app knows. Indeterminate: leave the width off and add .progress--indeterminate to the track.

Empty state

Say which kind of empty it is — nothing yet, nothing found, or not allowed — and give the one action that resolves it. Inside a .card for a panel, or .empty-state--bare straight on the page.
