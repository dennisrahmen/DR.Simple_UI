Tokens

the contract

Every colour in the library resolves through one of these. Each swatch reads its value from the loaded stylesheet, so the values below are the live ones. Use the toggles to see them remap.

Overriding: redefine tokens in your app's own stylesheet, loaded after the library — normally the --brand* family, --accent and --sidebar-active. The overview has a complete override file. Do not declare new token names in an app; add them to the library, release, and upgrade.
For a design tool: every token ships as machine-readable JSON at tokens/DR.Simple_UI.tokens.json — _content/DR.Simple_UI/tokens/DR.Simple_UI.tokens.json in a running app. Its blocks array is ordered: merge the blocks in order, applying each one whose media condition matches and whose selector matches the document root. :root appears more than once, so a map keyed by theme would lose blocks. Generated from the same parts as the stylesheet, so it cannot drift from the values below.
