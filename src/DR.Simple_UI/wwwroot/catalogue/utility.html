Utilities

tier 2 — classes

A short list of single-purpose classes, in @layer dr.utilities. Not a utility framework — the point of tier 2 is semantic classes, and a page assembled out of fifteen utilities has moved its design decisions into the markup where nobody reviews them.

The cascade layer is what makes these work at all. A utility is (0,1,0) and a component rule like .table th, .table td is (0,1,1), so before layers a utility silently lost every collision — .text-end on a table cell did nothing and read as broken rather than outranked. dr.utilities sits after dr.paint, so it now wins regardless of specificity.

Text

The alignment utilities are logical (start / end), so they mirror with the document direction like everything else in the library.

.text-truncate includes min-width:0 on purpose. Its usual parent is a flex item, which otherwise refuses to shrink below its content width and the ellipsis never appears — that is the single most common reason truncation “does not work”.

Layout

.dr-row, .dr-row-wrap and .dr-col are the arrangements that would otherwise be an inline style="display:flex; gap:8px" — which is most of them. .dr-push pushes everything after it to the far end.

These carry the dr- prefix because they are library-owned utilities in the shared namespace, where .row and .col are names an app is very likely to have already.

Hidden, but not gone

.visually-hidden takes text out of the rendering and leaves it in the accessibility tree — a name for an icon-only control, a table caption, the target of an aria-describedby. Add --focusable and it comes back when reached by keyboard, which is how a skip link works.

.dr-invisible is not a replacement for the hidden attribute: use the attribute, which also removes the element from the accessibility tree and the tab order. This is only for hiding something that must keep its space in the layout. .dr-busy dims a block and stops interaction while it reloads — pair it with aria-busy="true", which is the part that is announced.
