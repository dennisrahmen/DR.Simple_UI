Stat tiles

tier 2 — classes

One number that matters, with what it is and which way it moved. .stat-row lays a set of them out without a breakpoint.

The label goes above the value. A number read before its label has to be held in the head while the reader finds out what it means — and on a row of four tiles they do that four times.

A row of tiles

The value is tabular-nums: digits of differing widths make a polling dashboard reflow every time it updates, and a page that never sits still is a page nobody can read.

--good and --bad are judgement, not direction. More resolved is up and good; more open is up and bad. Put a Remix Icon arrow inside to carry the direction, so it survives the colour-blind palette, a greyscale print and forced colours.

Inside a card

A .stat-row directly inside a .card-body drops the gap and gets a dividing rule between tiles instead, so the card reads as one object rather than four floating numbers.
