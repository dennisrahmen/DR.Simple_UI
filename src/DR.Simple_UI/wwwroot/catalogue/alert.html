Alerts

tier 2 — classes

An inline banner that explains a state, in place, on the page. Four variants, same semantic families as the buttons and badges.

Use an alert for a condition that stays true while the page is open — degraded connection, read-only mode, an empty filter result. Transient feedback about an action the user just took belongs in a toast, which arrives with the tier-1 frame in 0.2.0.
