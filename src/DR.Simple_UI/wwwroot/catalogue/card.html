Cards

tier 2 — classes

Three parts, all optional except the outer one: .card holds the border and clips its children, .card-head is the title row, .card-body is the padded content. Put the markup you want inside — that is the point.

For a variant, write the markup you need and use a token for any colour. There is no card component and no variant parameter.

Head and body

.card-head is space-between, so the first child goes left and the rest go right. Group multiple right-hand items in .card-head-right so they share a gap.

Body only

Drop the head when the content names itself.

A table in a card

No .card-body — the table provides its own cell padding, and .card's overflow:hidden clips the first row's corners to the border radius.

Key/value rows

.kv pushes label and value apart; the value picks up the monospace token, which keeps numbers and IDs aligned down the column.

A caveat about the card's own content

.card-warning pins an amber strip to the card's bottom edge — a stale figure, a degraded source, a partial result. It is part of the card, which is why it is not an .alert: an alert is a statement about the page, and putting one inside a card makes the reader look for what else on the page is affected.
